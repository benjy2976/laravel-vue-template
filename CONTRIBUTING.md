# Contribucion y reglas para IA

- Antes de cualquier cambio, leer y aplicar `AGENT_PROTOCOL.md`.
- Revisar `docs/guia_IA.md`, `docs/convenciones.md` y `docs/procedimientos.md`.
- Para Laravel, aplicar tambien `src/AGENTS.md`.
- Mantener este repositorio como template generico; no introducir logica de negocio especifica sin aprobacion.
- Si aparece una regla nueva, proponer en que archivo de memoria debe vivir antes de aplicarla.
- Si se crea un modulo o area funcional, crear su `context.md` e indexarlo en `docs/guia_IA.md`.
